# Logo files

Drop these PNG files here. The site components expect these exact filenames.

| File | Used by | Variant needed |
|---|---|---|
| `iago-logo.png` | Nav (light cream background) | Full color, transparent background |
| `iago-logo-cream.png` | Footer (dark teal background) | Cream/white reversed, transparent background |
| `iago-icon.png` | Favicon, social avatar | The "i" mark only, 512×512 minimum |

**Recommended dimensions:** Width ≥ 1200px for the wordmark (it'll be displayed at ~160px in the nav, the high res keeps Retina/2× displays crisp).

**Background:** Save as PNG with transparency (alpha channel), not on a white square.
